# Fill Fusion — Colors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dark/inverted theme with a white background and per-voice colored VexFlow notation.

**Architecture:** Two file changes. `style.css` removes the dark background and SVG invert filter. `main.js` adds a `VOICE_COLORS` map and refactors `renderFill()` to set the VexFlow context color before drawing each voice individually.

**Tech Stack:** Vanilla JS, CSS3, VexFlow 4.x (loaded as global `Vex` via CDN script tag).

> **Note:** `main.js` is also modified by the hi-hat-bark and timing-interval feature branches. When merging all three, manual reconciliation of `main.js` will be needed.

---

## Project Context

No build step. `main.js` uses VexFlow (global `Vex`) to render drum fills as SVG into `#staff`. Currently uses `filter: invert(1)` on `#staff svg` so black VexFlow strokes are visible on the dark background. We replace this with a white background and per-voice colors set via VexFlow's context API before drawing each voice.

### Task 2: Add VOICE_COLORS and refactor renderFill()

**Files:**
- Modify: `main.js`

The current `renderFill()` collects all voices into shared arrays and draws them in one pass at the end. To color each voice individually, we track voice metadata (including name) per entry, format all voices together (VexFlow requires this for correct spacing), then draw each voice separately with its color applied to the context.

- [ ] **Step 1: Add VOICE_COLORS map after VOICE_CONFIG in main.js**

```js
const VOICE_COLORS = {
  crash:     '#e63946',
  hihat:     '#457b9d',
  hihatOpen: '#457b9d',
  hihatFoot: '#1d3557',
  highTom:   '#2a9d8f',
  midTom:    '#e9c46a',
  floorTom:  '#f4a261',
  snare:     '#6a4c93',
  kick:      '#264653',
};
```

- [ ] **Step 2: Replace the renderFill() function body**

Replace the entire `renderFill(fill)` function with:

```js
function renderFill(fill) {
  const container = document.getElementById("staff");
  container.innerHTML = "";

  const width = container.clientWidth || 800;
  const renderer = new Renderer(container, Renderer.Backends.SVG);
  renderer.resize(width, 220);
  const context = renderer.getContext();

  const stave = new Stave(10, 60, width - 20);
  stave.addClef("percussion");
  stave.addTimeSignature("4/4");
  context.setFillStyle("#000");
  context.setStrokeStyle("#000");
  stave.setContext(context).draw();

  const voicesWithMeta = [];

  for (const [voiceName, noteData] of Object.entries(fill.voices)) {
    const cfg = VOICE_CONFIG[voiceName];
    if (!cfg) throw new Error(`Unknown voice: "${voiceName}"`);
    const notes = noteData.map(([key, dur]) => new StaveNote({
      keys: [key],
      duration: dur,
      stemDirection: cfg.stemDirection,
      ...(cfg.isXHead ? { noteType: "x" } : {}),
    }));

    const voice = new Voice({ numBeats: 4, beatValue: 4 });
    voice.addTickables(notes);
    const beams = Beam.generateBeams(notes.filter((n) => !n.isRest()));
    voicesWithMeta.push({ voice, beams, voiceName });
  }

  const vfVoices = voicesWithMeta.map(({ voice }) => voice);
  new Formatter().joinVoices(vfVoices).format(vfVoices, width - 40);

  for (const { voice, beams, voiceName } of voicesWithMeta) {
    const color = VOICE_COLORS[voiceName] || "#000";
    context.setFillStyle(color);
    context.setStrokeStyle(color);
    voice.draw(context, stave);
    beams.forEach((b) => b.setContext(context).draw());
  }
}
```
